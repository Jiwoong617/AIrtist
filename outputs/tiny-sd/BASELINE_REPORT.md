## 1. 결론

원본 Tiny-SD를 이 PC에서 추가 학습 없이 실행해 512×512 이미지 51장을 생성했다. 품질 비교 표본은 **12개 간접 묘사 × 한국어/수동 영어 번역 × 2개 시드 = 48장**이며, 나머지 3장은 첫 생성과 동일 입력 반복 측정이다.

한국어 직접 입력은 이번 표본에서 음식·접시 같은 그림으로 반복적으로 벗어났다. 영어는 색·동물·용기·줄무늬의 일부를 반영했으나, 바나나·우산의 형태, 상하 관계, 정확한 개수는 충분히 반영하지 못했다. **한국어 직접 입력만으로 게임 품질이 확보됐다고 볼 수 없고, 영어 입력도 모든 간접 묘사를 해결하지 못한다.**

원본 필수 모델 파일은 **1,062,108,664바이트**다. 앱·번역·채점·런타임·EOS를 더하기 전부터 설치 목표를 62,108,664바이트 초과한다. 후속 경량화 검증이 필요하며, 경량화가 현재의 의미 해석 실패를 회복할 것이라고 가정하지 않는다.

## 4. FP16 실패와 대응

1. 원본 가중치를 FP16으로 실행한 첫 호출은 약 40.14초 뒤 전 픽셀이 검은 이미지가 됐으며, 비정상 수치를 정수 픽셀로 변환하는 경고가 발생했다. 해당 실행은 중단하고 **무효 결과**로 표시했다.
2. 매 디노이징 단계의 유한값 검사를 추가한 재실행에서 **step 0, timestep 999의 latent가 유한하지 않음**을 확인했다. VAE 복원 이전에 이미 실패했으므로 VAE만 바꾸어 해결됐다고 볼 수 없다.
3. 동일 가중치를 메모리에 FP32로 로딩해 별도 폴더에서 전체 실험을 수행했다. 유한값 검사와 단색 출력 거부를 적용한 상태로 51회가 완료됐다.

[최초 실패 주석](runs/baseline-20260913-01/summary.json) · [FP16 진단 결과](runs/diagnostic-fp16-01/summary.json)

이 결과는 **이 GPU·드라이버·라이브러리 조합의 실패**다. 모든 GPU에서 Tiny-SD FP16이 실패한다는 결론은 아니다. 텍스트 인코더·U-Net·커널 중 최초 비정상 수치의 근본 원인은 아직 분리하지 않았다. 라이브러리/백엔드 또는 정밀도 조합 비교는 후속 검증 항목이다.

## 5. 성능 실측

| 지표 | 실측값 | 해석 |
|---|---:|---|
| 라이브러리 import | 4.396초 | 모델 로딩과 별도 |
| 첫 모델 로딩·GPU 이동 | 1.403초 | 파일 해시 검사 후 캐시가 데워진 상태 |
| 첫 정상 생성 | 8.244초 | 이미지 저장 제외 |
| 이후 50회 평균 | 7.938초 | 동일 입력 반복 2회 + 품질 표본 48회 |
| 이후 50회 중앙값 | 8.113초 | 동일 설정 |
| 이후 50회 최솟값~최댓값 | 7.460~8.179초 | 데스크톱의 다른 부하가 통제되지 않은 실험 |
| 이후 50회 P95 | 8.172초 | nearest-rank 방식 |

| 생성 구간 RAM 최대 샘플 | 2,048,851,968바이트, 약 1.91GiB | 실험 Python 프로세스 RSS |
| Windows 프로세스 생애 최대 working set | 3,761,496,064바이트, 약 3.50GiB | OS 보고값 |
| PyTorch GPU allocated 최대 | 2,952,207,360바이트, 약 2.75GiB | PyTorch가 할당한 텐서 메모리 |
| PyTorch GPU reserved 최대 | 3,504,340,992바이트, 약 3.26GiB | PyTorch 메모리 풀 예약량 |
| GPU 장치 전체 최대 샘플 | 4,427MiB, 약 4.32GiB | 데스크톱·다른 앱 포함, 약 500ms 간격 |

가장 느린 품질 사례는 영어 빨간 용기, 시드 42의 8.179초였다. 같은 묘사·시드의 첫 호출과 반복 2회는 픽셀 해시가 일치했다. 현재 실행 범위에서 메모리 부족과 생성 실패는 없었고, 메모리 샘플러 오류도 없었다.

생성 시간에는 텍스트 인코딩·디노이징·VAE 복원·PIL 변환과 매 단계 유한값 검사 비용이 포함된다. PNG 저장은 별도 기록했다. 로딩 전에 파일 해시를 읽으므로 **깨끗한 PC의 최초 실행/콜드 디스크 로딩 측정은 아니다.** 6GB GPU·약 48GiB RAM 결과를 VRAM 4GB·RAM 16GB에서의 동작 보장으로 사용하지 않는다.
