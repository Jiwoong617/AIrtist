# 작업 폴더 용량과 필요한 파일

이 문서는 Git에 보관하지만 파일별 용량 스냅샷과 실험 산출물은 로컬에만 보관한다. 아래 집계 링크는 해당 개발 PC에서만 열 수 있다.

2026-09-13 측정 시 `D:\AIrtist`의 논리적 파일 크기는 **약 11.07GB**다. GB는 1,000,000,000바이트이며 실험 이미지가 추가되면 조금 늘어난다. 디스크 할당 크기와는 다를 수 있다. [파일별 집계](workspace-size.json)

| 구분 | 현재 크기 | 용도와 필요성 |
|---|---:|---|
| `.venv-tiny-sd` | 7.10GB | Python·PyTorch·CUDA·변환 도구. 현재 실험 재현용이며 최종 게임에 통째로 넣지 않는다. |
| `models` | 3.78GB | 원본, 양자화본, TAESD, ONNX 변환본을 비교하려고 함께 보관했다. 최종 게임에는 선정한 한 구성만 필요하다. |
| `outputs` | 약 0.19GB | 생성 이미지, 비교 결과, 프로파일, 보고서. 개발 검증 자료다. |
| 소스·문서·Git | 1MB 미만 | 실험 코드, 설정, 재현 및 측정 기록. 유지한다. |

**모든 파일이 최종 게임 실행에 필요한 것은 아니다.** 큰 항목은 다음과 같다.

- FP32 ONNX 중간 파일 2개는 **1.79GB**다. 저장 크기를 줄인 ONNX를 만들기 전의 산출물이며 현재 경량 ONNX 실행에는 사용하지 않는다. 변환 스크립트로 다시 만들 수 있다.
- 개발 환경 안의 PyTorch 정적 링크 라이브러리(`*.lib`)만 **2.82GB**다. 현재 개발 패키지에 함께 설치됐으나 Windows 게임의 런타임 DLL 크기와는 구분한다.
- 원본 Tiny-SD 약 **1.06GB**와 Quanto 비교용 변형 약 **0.33GB**도 원본/변환 검증용으로 보관한다. 최종 ONNX 구성과 중복되는 가중치다.
- 현재 선정 후보의 ONNX 생성 모델·토크나이저·스케줄러는 **약 580MB**, 확인한 ORT·DirectML DLL을 합치면 **약 619MB**다. .NET 앱·번역·채점·EOS·에셋을 포함한 전체 게임 크기는 아직 아니다.

현재 실험 환경과 증거를 유지했으며 파일을 삭제하지 않았다. 개발 환경은 후속 변환·검증이 끝난 뒤 제거해도 잠금 파일과 준비 스크립트로 재설치할 수 있다. 원본 모델과 변환 중간물도 재현 기록을 남기고 필요한 구성만 보관하는 방식으로 정리할 수 있다.
