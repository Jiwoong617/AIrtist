# 여러 PC 온라인 검사 절차

작성: 2026-10-05. **실행 준비 문서이며 여러 PC 검사 통과 기록이 아니다.**

## 준비

- Windows x64 PC 두 대와 각 PC의 인터넷 연결. 다른 회선 검사는 한 PC를 휴대폰 핫스팟 등 별도 회선에 연결한다. 같은 공유기 검사는 다른 회선 검사와 따로 기록한다.
- `D:\AIrtist\testbuild` **폴더 전체**를 각 PC에 준비한다. 두 PC의 `package-manifest.json` SHA256이 같은지 확인한다. EXE만 옮기지 않는다. 개발 SDK·Python·별도 모델 다운로드는 요구하지 않는다.
- 테스트 담당자가 EOS 설정 파일을 각 PC의 패키지 **바깥** 경로에 준비한다. 현재 개발 PC 파일은 `D:\AIrtist\config\eos.local.json`이다. 파일 내용을 채팅·결과 보고서·공개 저장소에 붙여 넣지 않는다. 다른 PC에 설정 파일을 자동 전송한 상태는 아니다.
- 각 PC에서 먼저 그림그리기 한 장이 생성되는지 확인한다. 낮은 사양의 실제 생성 성능은 아직 검증 전이다.
- 3인 투표 검사는 세 번째 PC/참가자가 필요하다. 같은 PC·같은 Windows 사용자의 앱 두 개를 별도 기기로 취급하지 않는다.

현재 개발 PC 실행:

```powershell
& 'D:\AIrtist\testbuild\AIrtist.exe' --eos-config 'D:\AIrtist\config\eos.local.json'
```

다른 PC는 실제 설치/설정 경로로 바꾸거나 EXE 실행 후 **온라인 방 → 파일 선택**으로 설정 파일을 고른다. 플레이어용 Epic/Steam 로그인은 이 검사 방식에서 요구하지 않는다.

## 2PC: 방 참가부터 두 라운드까지

1. A/B 모두 **온라인 방 → 접속**을 누른다. A에서 방 정원을 2로 설정하고 **방 만들기**, B에서 **방 검색 → 해당 방 선택 → 선택한 방 참가**를 누른다.
2. 양쪽 모두 `참가자 2/2명`인지 확인한다. A에는 `내가 방장`, B에는 `참가 중`이 표시되어야 한다. 검색 실패·명단 불일치는 이후 단계를 통과로 기록하지 않는다.
3. **양쪽 모두 연결 준비**를 누른다. 전원 합의가 끝나면 각자 **경기 대기방 열기**를 누른다. 한 명만 준비했을 때 경기 대기방이 열리면 실패다.
4. A가 검사 설정을 2라운드·작성 300초·생성 180초로 적용한다. 이는 수동 검사 여유 시간이며 제품 기본값 변경이 아니다. 양쪽이 준비한 뒤 A만 시작한다.
5. 같은 제시어/라운드가 표시되는지 확인한다. 각자 제시어와 금지 별칭을 쓰지 않은 서로 다른 묘사를 입력하고 번역을 확인·수정해 확정한다. 각 PC에서 한 장씩 생성한다.
6. 두 PC의 갤러리에 **두 그림이 모두 나타나는지** 확인한다. 서로의 그림에서 색·형태·배치를 비교하고, 자기 그림의 투표가 비활성화됐는지 확인한다. 화면 비교는 네트워크 경로나 PNG 해시를 별도로 실측한 기록을 대신하지 않는다.
7. 서로에게 투표한다. 양쪽 모두 **1:1**이며 동일한 라운드 결과인지 확인한다. 2인 검사에서는 정상적으로 이 동점 구조가 발생한다.
8. 전원 결과 확인 후 A만 다음 라운드를 시작한다. 새 입력·새 이미지로 5~7을 반복하고 첫 라운드 기록 보존·마지막 라운드 경기 종료·두 PC의 숫자 기록 일치를 확인한다.
9. 접속을 종료한다. 새로 접속해 방 생성/검색/참가가 가능한지 확인한다. 같은 경기의 진행 상태 복원은 지원하지 않는다.

## 3PC: 투표 집계

새 방에서 정원 3, 1라운드로 진행한다. 참가자 A/B/C가 각각 한 장 생성한 뒤 A→B, B→A, C→B로 투표한다. 모든 PC에서 A/B/C 그림의 득표가 **1/2/0**이어야 한다. 자기 투표·중복 확정이 허용되지 않는지 확인한다. 이 인원은 테스트 조건이며 제품 최소 인원 확정이 아니다.

## 이탈과 실패

별도 방에서 참가자 연결 준비 이후 한 참가자가 **접속 종료**한다. 나머지 참가자가 계속 경기 시작/진행하지 않고 중단 상태로 바뀌는지 확인한다. 다시 모일 때는 전원이 나간 뒤 새로 접속한다. 호스트 이전·진행 중 재접속은 지원하지 않는다. 확정된 라운드 결과가 있다면 남은 화면에서 보존되는지 확인한다.

실패 시 먼저 발생한 단계·화면의 오류 문구·각 PC의 상태를 기록한다. 새 방으로 재시도하되 방화벽/보안 설정을 임의로 끄지 않는다.
