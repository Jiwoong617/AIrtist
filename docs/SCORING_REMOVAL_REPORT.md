# AI 채점 제거·패키지 검증 — 2026-09-22

수정 기획의 **2번 작업을 완료했다.** 제품의 채점 코드·모델·벡터와 패키징 의존성을 제거하고 멀티플레이용 단어 목록을 독립 데이터로 분리했다. 현재 실행 파일은 `testbuild/AIrtist.exe`이며 폴더 전체가 필요하다. 다음은 멀티플레이 그림 모아보기·투표·호스트 집계다.

## 수행한 검사

- 잠금 파일 기반 복원, 단위 검사, Release 자체 포함 publish·패키징 성공. .NET SDK 10.0.103, 자체 포함 런타임 10.0.3 / win-x64, ORT 1.22.0, DirectML 1.15.4 유지.
- 단어/자산: 독립 단어 목록 로딩, 잘못된 ID·뜻·별칭 거절, 공백·유니코드·영어 별칭의 멀티 금지와 그림그리기 허용 분리, 채점 없는 manifest 통과, 구형 버전·다른 profile·누락·추가·중복·경로 이탈·파일 손상 거절.
- 그림그리기 규칙: 번역 확인·수정·직접 대상명·반복, 중복/오래된 명령, 실패·취소·시간 초과·종료 후 늦은 결과 처리 통과.
- 참조 검사: 생성용 CLIP 토크나이저 13문장, Marian 토크나이저/번역 12문장, DPM 스케줄러 25단계 통과. 스케줄러 최대 오차 0.000003814697265625.
- 실제 새 EXE: 한국어 직접 대상명 → 번역 확인 → 영어 확인란 한글 거절 → 원문 복귀 → 영어 수정 → 생성 → 같은 묘사 반복 → 새 원문 생성까지 **3장** 성공. 전체 76.992초, UI Dispatcher 662회 응답. 생성은 24.965 / 21.933 / 21.818초였다.
- 별도 실제 반복 검사: 같은 프로세스에서 **6장** 생성(각 20.47~21.34초), U-Net 진행 중 취소(9.90초), 기술 제한 시간 초과(10.19초), 이후 생성 복구 통과. 시간 초과 사례만 10초 제한의 별도 컨트롤러를 사용했고 같은 AI 실행 객체를 재사용했다. 강제 GC 없이 메모리를 기록했다.
- 새 패키지에 채점 모델·벡터·TinyCLIP 전용 고지가 없으며 단어 파일이 원본과 동일함을 확인했다. 등록 파일 **438개** 크기·SHA-256과 전체 **439개** 파일을 검사했다.
- .NET·ORT·DirectML의 패키지 내 로딩을 확인하고 `testbuild`로 교체한 후 최종 경로 자체 검사에 통과했다. 불필요한 파일 정리 후에도 전체 패키지 해시가 일치했다.
- Python 준비/실험 소스 9개의 구문 검사, PowerShell 변경 스크립트 구문 검사, Python 호환 진입점의 실제 manifest 준비, `git diff --check` 통과. 기존 `.gitignore`가 새 패키지·모델·검사 출력을 제외함을 확인했다.

측정 GPU는 GTX 1660 Ti 6GB / 드라이버 591.86이다. 패키지 진단의 최대 working set은 **1,695,981,568바이트**, private bytes는 **3,606,220,800바이트**다. 별도 반복 검사 최대 working set은 **1,719,459,840바이트**, private bytes는 **3,621,257,216바이트**다. 반복 검사 완료 직후 private bytes는 첫 345,899,008 → 마지막 448,335,872바이트로 남았으므로 장시간 누수 없음으로 판정하지 않는다. GPU 측정은 다른 앱을 포함한 전체 값이며 앱 전용 VRAM·최소 사양·속도 개선 수치가 아니다.

원자료는 `outputs/scoring-removal/packaged-drawing/`, `final-path-check/`, `package-verification.json`, `outputs/drawing-stability/20260922-104145/results.json`, `outputs/app-stage3/csharp-reference-checks.json`에 있다. 진단 기록의 `testbuild-no-scoring`은 최종 `testbuild`로 옮기기 전 경로다.

## 남은 검증과 다음 작업

이번 검사는 현재 개발 PC에서 동봉 모델과 로컬 런타임만으로 추가 다운로드 없이 실행했다. 실제 네트워크 차단, 개발 도구 없는 깨끗한 Windows, 4GB VRAM/16GB RAM, 장시간 반복, 물리 IME·DPI 전환은 별도 검증이 필요하다. 자동 번역의 의미 왜곡과 생성 품질 전체를 개선하거나 통과시킨 작업도 아니다.

다음은 **멀티플레이 그림 모아보기·1인 1표·자기 그림 투표 금지·호스트 집계**를 구현한다. 투표 시간·선택 변경·기권·동점·실패/이탈자의 자격·누적 결과는 미정임을 유지하고 확정하거나 변경 가능한 임시값을 명시한다. 그 다음 EOS 로비·P2P 이미지 전송·결과 동기화와 실제 여러 PC 검증을 진행한다.
