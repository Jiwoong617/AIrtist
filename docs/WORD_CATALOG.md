# 멀티플레이 제시어 목록

갱신일: 2026-10-19. `data/words.json`을 **8개에서 120개**로 확장했다.

## 모델과의 관계

이 JSON은 멀티플레이의 출제·화면 표시·금지 별칭 검사에 사용한다. Tiny-SD의 학습 자료나 생성 가능 대상을 제한하는 목록이 아니다. `LocalDrawingAi`와 `LocalGenerator`는 플레이어의 묘사·번역과 공통 스타일을 사용하며, 현재 정답이나 이 목록을 생성 프롬프트에 넣지 않는다.

그림그리기 모드는 제시어 목록 없이 자유 입력을 사용하므로, 목록에 없는 대상도 생성할 수 있다. 단어를 추가해도 모델 가중치·학습 범위·생성 품질은 바뀌지 않는다. 대상마다 품질이 다를 수 있으며 이번 목록 추가는 120개 대상의 실제 생성 품질을 모두 검수했다는 뜻이 아니다.

## 관리 기준

- `id`: 저장·동기화에 사용하는 고유 식별자. 기존 ID를 다른 뜻으로 재사용하지 않는다.
- `korean`: 플레이어에게 보이는 이름.
- `meaning`: 대상의 뜻과 범위. 정답 별칭이 들어갈 수 있으므로 그대로 제출하는 예시 문장은 아니다.
- `english`: 대상의 영어 이름.
- `aliases`: 직접 답을 쓰는 것을 막기 위한 한국어·영어 이름, 주요 동의어·표기·복수형. 모든 우회 표현을 탐지하는 보장은 아니다.

기존 유니코드 정규화·공백/구두점 제거·부분 문자열 금지어 검사 규칙을 유지한다. 짧은 별칭이 다른 문장 일부와 겹쳐 과잉 차단될 수 있는 기존 제약은 남아 있다. 다른 단어의 별칭까지 한꺼번에 금지하지는 않으며, 현재 라운드의 제시어에 대해서만 검사한다.

실행 패키지는 `testbuild/data/words.json`을 사용하고, 일반 빌드는 소스의 `data/words.json`을 복사한다. 단어 파일의 해시도 멀티플레이 호환성에 포함되므로 함께 플레이할 참가자는 같은 목록을 사용해야 한다. 규칙 식별자는 `multiplayer-results-v9`를 유지한다.
