빈 `dist`, `.cache/release-20261001`, `.cache/gpu-fix-20261003` 폴더도 제거했다. `.git` 제외 작업 폴더의 논리적 파일 합계는 약 **8.86GB → 3.29GB**다. 새 정리 기록 때문에 정확한 전체 크기는 조금 늘어날 수 있다.

## 보존·검증

- Git 추적 파일과 Git 제외가 아닌 신규 소스·문서 235개의 정리 전후 SHA256 일치를 확인했다. 삭제 대상은 모두 Git 제외 파일이었다.
- 최신 `testbuild`는 **943,598,864바이트 / 444개 파일**로 유지했다. manifest에 기록된 필수 파일 443개의 길이와 SHA256을 모두 재검사했다.
- 모델 원본·실행 모델, EOS SDK·로컬 설정, 내장 설정 생성 리소스, NuGet 의존성 캐시와 실제 생성 PNG·검사 결과·요약 보고서·라이선스는 보존했다.
- 과거 문서에서 보존했다고 기록한 `testbuild-before-*` 백업은 이번 정리로 제거됐다. 현재 배포본은 `testbuild`다.
- 코드 변경이 없는 파일 정리이므로 앱 동작 검사는 반복하지 않았다. 직전 실제 2인 생성·투표와 2/3인 회귀 검사 결과는 [종료 오류 수정 기록](GALLERY_CRASH_REPORT.md)에 있다.

`obj`도 제거했으므로 다음 빌드는 복원 단계를 포함한 `./scripts/build-app.ps1`을 사용한다. 복원 전 `dotnet publish --no-restore`만 실행하면 필요한 중간 파일이 없다.

세부 삭제 목록과 보존 검사는 Git 제외 `.cache/cleanup-plan-20261017.json`, `.cache/cleanup-result-20261017.json`, `.cache/cleanup-verification-20261017.json`에 기록했다.
