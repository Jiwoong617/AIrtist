# 작업 폴더 정리 — 2026-10-19

사용자 요청으로 최신 실행 패키지와 개발에 필요한 파일을 보존하고, 중복 빌드·이전 백업·재생성 가능한 상세 로그를 제거했다.

| 합계 | **1,196** | **603,620,549** |

약 604MB를 확보했다. 앞선 라이선스 작업에서 이미 제거한 임시 패키지 2개는 이번 합계에 포함하지 않았다.

## 보존·검증

- 삭제 전에 모든 대상의 절대 경로가 작업 폴더 안인지 확인하고, 링크 경로와 Git 제외가 아닌 파일을 거절했다.
- Git 추적 파일과 신규 소스·문서 등 273개의 삭제 전후 SHA-256이 일치했다. 이 정리 보고서와 관련 문서 갱신은 그 확인 이후 작성했다.
- `testbuild`는 **953,049,536바이트 / 459개 파일**로 유지했다. manifest에 기록된 458개 항목의 길이·SHA-256과 manifest 자체의 해시를 삭제 전후 확인했다.
- 모델 원본·실행 모델·토크나이저, EOS SDK와 로컬 연결 설정, 내장 설정 생성 리소스, NuGet 의존성 캐시를 보존했다.
- 라이선스 원문·고지, 음원과 제작 원본 WAV, 실제 생성 PNG, 검사 결과·요약 보고서·화면 캡처를 보존했다.
- 이전 사운드·최종 결과·라이선스 보고서의 백업 경로는 당시 기록이다. 해당 `testbuild-before-*` 백업은 이번 정리로 제거됐다.

실행 코드나 패키지를 변경하지 않은 정리이므로 앱 실행 검사는 반복하지 않았다. 직전 실제 싱글 3장·로컬 모의 3인 2라운드·라이선스 UI 검사는 [라이선스 적용 보고서](LICENSE_IMPLEMENTATION_REPORT.md)에 있다.

`obj`도 제거했으므로 다음 빌드는 복원 단계를 포함한 `./scripts/build-app.ps1`을 사용한다. 복원 전 `dotnet publish --no-restore`만 실행하지 않는다.

상세 계획·삭제 결과·소스 해시는 Git 제외 `.cache/cleanup-plan-20261019.json`, `.cache/cleanup-result-20261019.json`, `.cache/cleanup-source-hashes-20261019.json`에 기록했다.
