## 실행

`D:\AIrtist\testbuild\AIrtist.exe`를 실행한다. **testbuild 폴더 전체**에 모델·토크나이저·벡터·.NET/WPF·ONNX Runtime·DirectML·고지가 포함된다. EXE만 복사하면 실행할 수 없다. Python이나 모델의 추가 다운로드는 필요하지 않다.

현재 크기는 **955,637,367바이트(955.64MB), 442개 파일**, 1,000,000,000바이트 기준 여유는 **44,362,633바이트**다. 압축 설치 파일이 아닌 실행 폴더의 파일 크기 합이다. [크기 기록](../outputs/cleanup/testbuild-size.json)

현재 소스 Release 빌드(경고·오류 0), 규칙 검사, 패키지 442개 파일 목록·해시, 빌드된 앱/Core DLL과 패키지 DLL 일치를 확인했다. `testbuild` EXE로 한국어 실제 생성·건너뛰기·영어 실제 생성·3라운드 최종 결과·새 경기 초기화를 통과했다. 진단 약 49.99초 동안 UI 타이머 418회, 합계 159.70/평균 53.23점으로 기록됐으며 .NET·ORT·DirectML은 모두 testbuild에서 로드했다. [경기 진단](../outputs/cleanup/testbuild-smoke-20260920/match-smoke.json), [실행·모듈 기록](../outputs/cleanup/testbuild-smoke-20260920/process.json)

당시 번역 의미 보존과 채점 정확도는 미달이었다. 이 정리 작업에서 모델 품질을 개선한 것은 아니다. 현재는 AI 채점 개선을 중단했으며, 그림그리기 전환·멀티 투표·4GB VRAM/16GB RAM·깨끗한 PC 검증이 남아 있다.

## 이후 빌드

2026-09-20 채점 개선 후 `testbuild`는 **963,310,223바이트**, 전체 작업 폴더는 **약 3.80GB**다. TinyCLIP 40M 원본 약 339MB를 개발용으로 보관하며 위 표는 이전 정리 시점의 값이다. 이번 실험의 CPU Python 환경·이전 패키지·중간 모델·중복 빌드 산출물 약 5.22GB는 검증 후 제거했다. 기존 8M 원본은 자동 승인 검토가 재현용 원본 삭제를 거절해 보존했다. [후속 품질·용량 결과](APP_QUALITY_REPORT.md)

준비된 모델이 있는 현재 PC에서 Python 없이 다음 명령으로 새 폴더에 패키징한다.

```powershell
.\scripts\build-app.ps1 -CheckRules -PackageDirectory testbuild-new
```

기존 폴더는 덮어쓰지 않는다. `scripts/package-app.ps1`이 모델 manifest의 크기·해시를 검사하고 필요한 파일과 고지만 복사한다. 현재 모델 준비 명령은 `scripts/prepare-runtime-assets.ps1`이며 의도적인 모델·설정 변경 후에만 실행한다. 원본·변환 환경 재현은 [개발 안내](APP_DEVELOPMENT.md)를 따른다.

`testbuild/`, 모델, 캐시, 실행 로그는 `.gitignore`에서 제외한다. 재현에 쓰는 검사 소스와 빌드 스크립트는 보관한다.

검증 후 13개 경로에서 **1,981,851,422바이트**를 정리했다. 이전 패키지 963,329,453바이트, 이번 publish·App/Core/Checks의 bin/obj 542,335,583바이트, 앱용 채점 파일과 8M/40M 원본 476,186,386바이트다. 경로가 프로젝트 내부인지, Git 추적 파일·재분석 지점·이전 패키지의 변경/추가 파일이 없는지 검사했다. 채점 원본은 고정 출처의 크기·해시와 대조했고 `experiments/app_quality`의 출처 JSON 및 이전 변환·고지 기록을 보존했다. 이전에 보존했던 8M 원본도 이번 채점 모델 제거 범위에서 정리했다.
