# 최신 testbuild 교체·실행·용량 검증

**현재 배포본 — 2026-10-05:** `D:\AIrtist\testbuild\AIrtist.exe`, 폴더 전체 **943,420,637바이트 / 444개 파일**. 온라인 종료가 즉시 완료된 경우 창 닫기 중첩 예외를 수정했다. Release 빌드·모의 3인 2라운드/종료 회귀·최종 패키지의 실제 EOS 단일 참가자 인증/방 검색·생성·나가기/재접속/정상 종료와 초기 화면 검사가 통과했다. 실제 여러 PC 참가·P2P·PNG·온라인 투표는 미검증이다. [현재 변경·실측·명령](ONLINE_LIVE_REPORT.md)

10월 4일의 GPU 공급자 재사용/취소 수정과 실제 30장·복구·배포 AI 검증은 [GPU 보고서](GPU_RESOURCE_FIX_REPORT.md)에 있다. 이번에는 AI 생성 코드·모델을 바꾸지 않았으며 해당 검사를 반복하지 않았다.

아래 수치·해시·검사·정리는 **2026-10-01~02 당시 기록**이다. 현재 실행 안내와 완료 범위는 위 최신 보고서를 우선한다.

빌드·실행 검사: 2026-10-01 / 중단 후 상태 확인·문서 마무리: 2026-10-02

## 실행과 완료 범위

`D:\AIrtist\testbuild\AIrtist.exe`를 실행한다. **폴더 전체가 필요하며 EXE만 복사하면 실행되지 않는다.** 모델 경로 옵션 없이 동봉한 번역/생성 모델을 사용한다.

- 그림그리기: 자유 입력·번역 확인/수정·생성·다시 그리기.
- 경기 미리보기: 한 PC에서 2~4명의 역할을 바꾸는 실제 AI 경기. 준비·방장 시작·1~10라운드·그림 공유·투표·라운드별 기록을 포함한다.
- 온라인 방: EOS 설정 선택·접속·방 생성/검색/참가·전원 연결 준비·대기방/경기 화면을 포함한다. **포털 설정 5개가 없어 실제 EOS 인증과 인터넷 송수신은 미검증이다.**

기존 9월 23일의 PNG 선택형 투표 미리보기 패키지를 최신 소스로 교체했다. 앱 소스는 직전 온라인 화면 구현을 그대로 사용했고 이번에는 새 기능이나 모델을 추가하지 않았다. `testbuild`는 로컬 개발용 실행 폴더이며 설치 프로그램은 아니다.

실제 AI 검사는 **한 PC의 메모리 내 전송**이다. 온라인 모의 검사와 실제 AI 경기를 합쳐 실제 EOS 접속이 검증됐다고 해석하지 않는다. 이번에는 앱 소스를 변경하지 않아 직전 전체 Core 규칙 검사와 EOS 경계/native 검사를 다시 반복하지 않았다.

실행 환경은 GTX 1660 Ti 6GB·드라이버 591.86, .NET SDK 10.0.103/런타임 10.0.3, ONNX Runtime DirectML 1.22.0/DirectML 1.15.4다. 기존 Tiny-SD 혼합 INT8·TAESD 구성, 512×512·25단계·guidance 7을 사용했다.

- 그림그리기 첫 생성 20.99초, 이후 생성 20.79/20.75초. 모델 로딩이 포함되며 최초 로딩만 별도 측정하지 않았다. 검사 전체 68.20초.
- 경기 승인·생성·로컬 업로드는 장당 21.19~21.96초. 사과/자동차 제시어를 직접 넣지 않는 묘사를 번역 확인·수정 후 제출했다. 검사 전체 147.01초, UI 타이머 1,322회.
- 최대 표본 working set은 그림그리기 1,745,682,432바이트/경기 1,841,201,152바이트, private bytes는 각각 3,599,941,632/3,715,489,792바이트다.
- 전체 GPU 사용량 최대 표본은 각각 3,936/3,884MiB다. 다른 앱을 포함한 GPU 전체 값이며 이 앱 전용 VRAM 최대치나 4GB 최소 사양 검증이 아니다.
- 약 0.5초 간격 표본이며 순간 최대 메모리·장시간 안정성은 미측정이다. 번역 정확도가 개선됐거나 생성 품질 전체가 합격했다고 판단하지 않았다.

검사 결과·이미지·프로세스 기록은 `outputs/release-20261001/`에 있다. `package-size.json`, `integrity-before.json`, `final-verification.json`, 각 검사 폴더의 `status.json`과 `process.json`을 보존했다. 10월 2일 재개 시에는 저장 상태 확인과 문서 정리를 수행했으며 AI 생성을 다시 실행하지 않았다.

## 교체와 정리

후보 패키지를 먼저 검사하고 기존 `testbuild`를 임시 보관한 뒤 최종 경로로 옮겼다. 최종 실행·무결성 확인 후 기존 패키지와 이번 publish 복사본 **1,128,120,428바이트**를 정리했다. 삭제 전 경로 범위·재분석 지점·Git 추적 여부·파일 목록과 기존 패키지 해시를 확인했다. 소스·개발용 모델·SDK·검사 결과는 유지했다.

정리 직후 전체 작업 폴더 파일 합계는 **3,732,357,146바이트(약 3.73GB)**였다. 이후 문서·검사 기록 때문에 소량 늘어날 수 있다. 실행에 필요한 것은 약 943MB의 `testbuild` 전체 폴더이고 나머지는 개발·재현용이다.

변경 기록은 이 보고서, `docs/EOS_DISTRIBUTION_REPORT.md`, `config/eos-sdk-lock.json`의 배포 확인 메모와 루트/실행/정리 문서에 반영했다. 실행 파일·모델·설정·진단 산출물은 기존 Git 제외 규칙을 유지한다. 커밋·외부 게시를 수행하지 않았다.

## 다음 작업과 미검증 항목

1. `config/eos.local.json`에 Product/Sandbox/Deployment/Client ID·Client Secret과 포털 정책을 준비한다. 비밀값은 채팅이나 Git에 올리지 않는다.
2. 실제 기기 인증·취소/갱신·서비스 방 생성/검색/참가·이탈을 검사한다.
3. 다른 회선의 2대 PC에서 실제 PNG를 전송하고, 3명 이상으로 투표·여러 라운드 기록 일치를 검사한다.
4. 개발 도구가 없는 Windows의 최초 실행·네트워크 차단 상태의 그림그리기, 낮은 사양·장시간·실제 IME/DPI와 외부 배포 조건을 검증한다.

현재 검사 PC에서 추가 모델 다운로드 없이 실행한 결과이며 깨끗한 PC/실제 네트워크 차단 검사는 아니다. 최종 우승 기준·자동 재접속·동적 명단 재합의·호스트 이전도 남아 있다.
