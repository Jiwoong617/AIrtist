# 메인 메뉴와 바로 그리기 — 2026-10-07

## 실행과 사용

`D:\AIrtist\testbuild\AIrtist.exe`를 실행한다. 모델·런타임을 포함한 폴더 전체가 필요하다. 전체 크기는 **943,470,926바이트 / 444개 파일**이며 1GB 목표 이하다.

- 메인: 제공된 목업처럼 흰 배경에 AIrtist 제목과 그림 그리기·멀티 플레이·설정·종료를 중앙 배치했다.
- 그림 그리기: 원문과 CFG·Steps·Seed를 입력하고 **그림 그리기** 한 번으로 내부 번역과 생성을 진행한다. 번역본이나 확인 버튼은 표시하지 않는다. 완료 후 원문을 직접 수정하거나 같은 버튼으로 다시 그린다.
- 멀티 플레이: 기존 온라인 방 생성·검색·참가 화면으로 이동한다. 실제 접속에는 별도 EOS 설정 파일이 필요하다. 묘사를 입력하고 그림 그리기를 누르면 번역 후 자동으로 제출하고 방장 승인 뒤 한 장을 생성한다.
- 설정: 1120×820, 1280×900, 1600×900, 1920×1080의 창 크기 선택과 BGM/SFX 0~100% 슬라이더를 제공한다. 큰 창은 Windows 작업 영역에 맞춘다. WPF 창의 논리적 크기이며 모니터 해상도나 생성 이미지 해상도를 바꾸지 않는다. 이미지는 기존 512×512다.
- 적용한 설정은 `%LOCALAPPDATA%\AIrtist\settings.json`에 저장하고 재실행 시 읽는다. BGM/SFX는 값 저장만 구현했으며 사운드 재생은 아직 없다.
- 싱글·멀티의 메인 화면 버튼으로 돌아온다. 싱글 생성 중에는 취소와 작업 정리를 마친 뒤 닫는다. 멀티는 기존 연결 정리를 거친다.

## 구현과 유지한 규칙

`MenuWindow`가 앱 시작 창이다. 설정 및 모드 선택을 담당하고 창을 전환하는 동안 메인 메뉴를 숨겼다가 다시 표시한다. `GameSettings`가 값 검증·저장·창 크기 적용을 담당한다. 실제 AI는 공유 직렬 실행기를 사용한다.

싱글 `DrawingController.DrawAsync`는 원문/파라미터 검증 → 번역 → 번역 형식 검사 → 이미지 생성을 하나의 취소 가능한 작업으로 실행한다. 번역 실패·취소·시간 초과 뒤 생성하지 않으며 늦은 결과는 기존 그림을 덮어쓰지 않는다. 한 번 클릭 전체의 기술적 제한 시간은 180초다. 중복 클릭은 추가 작업을 시작하지 않는다.

멀티 `MultiplayerRoundRuntime.Draw`와 Match/worker 명령이 내부 번역 완료 후 기존 `Confirm` 제출 경로를 호출한다. UI 타이머가 자동 승인하는 구조가 아니며, 원문·번역의 금지어 검사와 호스트 승인/생성권 검증은 그대로다. 번역은 작성 마감 안에 끝나야 하고 번역 실패·취소·금지어 실패만으로 생성권을 소비하지 않는다. 호스트 승인 후 생성 실패는 기존 한 번 생성 규칙을 따른다. 방 고정 파라미터와 참가자별 자유 파라미터 모두 지원한다.

기존 번역 확인 Core API와 숨겨진 검사 컨트롤은 이전 진단 호환성을 위해 유지한다. 제품 버튼은 새 단일 클릭 경로를 사용한다. 전송 계약과 규칙 버전 `multiplayer-parameters-v7`은 변경하지 않았다. 자동 번역 품질이 개선된 것으로 해석하지 않는다.

## 검증

- Release 빌드·게시 성공, 전체 `unit` 검사 통과.
- 새 단일 클릭 Core 검사: 입력 변경, 내부 번역, 반복, 중복 요청 거절, 번역 실패/취소, 시간 초과 뒤 늦은 그림 거절과 재시도.
- 멀티 Core 검사: 자유/고정 파라미터의 자동 제출, 번역 취소/작성 마감 뒤 자동 생성 방지, 번역에 정답이 포함된 경우 생성권 보존과 재시도.
- `menu-smoke`: 실제 화면 이벤트로 시작 메뉴, 설정 저장/적용, 싱글·멀티 이동과 복귀, 종료를 검사한다. 한국어 입력의 실제 생성, 같은 Seed 반복, 원문·파라미터 변경의 실제 생성 총 3장을 포함한다.
- `online-smoke`: 자동 제출 UI/worker를 통해 자유/고정 방 각각 모의 3인·2라운드, 모의 이미지 6장과 투표 결과 동기화를 검사한다. 실제 EOS/인터넷 검사가 아니다.
- 메인·설정·그림그리기 화면 PNG를 육안 확인했다.
- 배포 목록의 443개 파일 크기/SHA-256 일치, 목록 파일 포함 총 444개다. EOS 로컬 설정 미포함을 확인했다.
