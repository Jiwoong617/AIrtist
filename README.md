# AIrtist

AIrtist는 **단어를 글로 묘사하고, AI가 그린 그림으로 겨루는 파티 게임**입니다. 플레이어는 직접 그림을 그리는 대신, 떠올린 모습이 그림에 담기도록 문장을 만듭니다.

매 라운드 모두에게 같은 제시어가 주어집니다. 단, 묘사에는 제시어를 직접 쓸 수 없습니다. 제시어가 **사과**라면 **“아삭아삭하고 빨간 과일”**처럼 색, 모양, 특징을 풀어서 표현해야 합니다.

그림을 생성할 기회는 라운드마다 한 번입니다. 같은 단어를 보고도 서로 다른 묘사를 떠올리고, AI는 그 문장을 때로는 의도대로, 때로는 예상 밖의 그림으로 바꿉니다. 어떤 특징을 골라 어떻게 설명할지가 게임의 핵심입니다.

완성된 그림들을 함께 보며 제시어를 가장 잘 표현했다고 생각하는 다른 사람의 그림에 투표합니다. 모든 라운드에서 받은 표를 합산해 가장 많은 표를 받은 플레이어가 1위가 되며, 동점이면 공동 1위가 됩니다.

혼자서는 제시어나 경쟁 없이 원하는 장면을 자유롭게 묘사하며 그림을 만들 수 있습니다. 문장을 바꾸었을 때 그림이 어떻게 달라지는지 살펴보며 자신만의 표현을 찾아가는 공간입니다.
