# AIrtist

Windows PC용 로컬 AI 그림그리기·멀티플레이 게임. **2026-09-21 기획 변경으로 AI 채점을 폐지**한다. 그림그리기 모드는 제시어·채점 없이 자유롭게 생성하며, 멀티플레이는 참가자 그림들을 함께 보고 다른 사람의 그림 하나에 투표한다. 자기 그림에는 투표할 수 없다.

현재 C#·WPF 앱은 **그림그리기 모드·경기 미리보기·개발용 온라인 방**을 제공한다. 그림그리기는 자유 입력 → 번역 확인·수정 → Tiny-SD 생성 → 다시 그리기 흐름이다. 경기 미리보기는 한 PC에서 2~4명의 역할을 바꾸며 1~10라운드를 진행한다. 온라인 방은 EOS 인증·방 생성/검색/참가·전원 연결 준비 후 대기방과 경기 화면을 사용한다. **2026-10-04 포털 설정과 별도 도구의 실제 EOS 인증·단일 참가자 방 검색/생성/나가기 검사를 완료했다.** 다른 PC의 실제 방 참가·P2P 이미지 전송·온라인 투표는 미검증이다. 최종 우승 기준은 미정이다. [EOS 설정·실측](docs/EOS_SETUP.md)

**실행:** `D:\AIrtist\testbuild\AIrtist.exe`. 2026-10-05 온라인 창 종료 수정을 반영한 폴더 전체는 **943,420,637바이트 / 444개 파일**이다. 모델·런타임을 동봉하며 EXE만 복사하면 실행되지 않는다. 최종 패키지에서 실제 EOS 단일 참가자의 로그인·방 검색/생성/나가기·재접속·종료를 확인했다. 기존 GPU 자원/취소 수정과 AI 검사 기록은 유지한다. 수 시간 사용·저사양/깨끗한 PC와 여러 PC 온라인 경기 검증은 남아 있다.

2026-10-01 연결 합의 단계를 정리했다. 공통 연결/참가 세션 ID·전원 P2P 준비와 Core 대기방 전달을 추가하고, 모의 3인 합의→대기방 준비→경기 시작 및 변경 중단·전체 규칙 검사·Release 빌드를 통과했다. 실제 서비스 접속과 온라인 화면은 아직 연결 전이다. 아래 항목은 날짜별 진행 기록이다.

2026-09-30 후속으로 EOS 로비 생성/검색/참가/나가기와 서비스 명단 확인을 추가했다. 로비/P2P 대역 검사와 SDK 초기화/종료·빌드는 통과했다. 실제 서비스 접속은 포털 설정이 없어 미검증이며, 공통 연결 범위·전원 준비 확인과 온라인 화면이 남아 있다. `testbuild`는 그대로다.

2026-09-30 EOS P2P 어댑터와 공통 전송 계약을 추가했다. SDK 경계 대역·기존 전체 규칙·대기방 화면 검사를 통과했으며, 실제 인증·온라인 송수신은 포털 설정이 없어 미검증이다. 다음은 EOS 로비 생성/검색/참가와 서비스 명단·전원 연결 준비 확인, 온라인 화면 연결이다. 아래 날짜별 미준비 기록은 당시 상태다.

2026-09-24 소스에는 호스트의 한 라운드 제출 승인·이미지 패킷 처리·투표 진입을 추가했다. 실제 생성 PNG 3장의 모의 송수신·결과 일치와 전체 규칙 검사를 통과했다. EOS SDK·프로젝트 설정이 아직 없으므로 실제 온라인 접속은 미구현이다. 기기 ID 인증을 작업 기준으로 두고 준비 절차·빈 설정 예제를 추가했다. `testbuild`는 아래의 기존 실행 파일 그대로다.

2026-09-25에는 참가자별 갤러리 복원·전원 확인 후 투표 시작·투표/확정 결과 적용을 추가했다. 독립된 모의 참가자 상태 3개에서 그림과 결과 일치를 검사했다. 실제 EOS 송수신·온라인 화면·여러 라운드는 남아 있으며 이번 변경도 소스와 Core 검사 단계다.

2026-09-26에는 제어 메시지 분할·재전송·ACK·중복 처리 방지·큐/속도 제한을 추가했다. 모의 3인 갤러리·투표에서 제어 패킷 30개 누락 후 결과 일치, 실제 로컬 UDP 소켓에서 32KiB 제어 본문 누락 복구를 확인했다.

2026-09-27 한 라운드 실행기와 AI/UI 연결에 이어, 2026-09-28 여러 라운드·결과 확인·기록 보존을 연결했다. 현재 규칙은 `multiplayer-match-v6`다. 실제 3명 × 2라운드에서 6장을 생성하고 각 라운드 1/2/0표와 전체 기록 일치를 확인했다. [최신 보고서](docs/MATCH_RUNTIME_REPORT.md)에 실행 방법과 한계를 기록했다. 실제 EOS SDK·설정은 아직 없으며 온라인 플레이·다른 PC 검증은 남아 있다. `testbuild`는 갱신하지 않았다.

2026-09-23 당시 검증한 `testbuild/AIrtist.exe`는 **922,301,469바이트 / 439개 파일**이었다. 현재 패키지는 위 최신 기록을 따른다. 그림그리기의 작성·번역 확인에는 마감이 없고 번역/생성 각각의 기술적 처리 제한은 180초다. 별도 투표 미리보기의 임시 투표 시간은 60초다. 당시 EOS·설치 프로그램·저사양/깨끗한 PC 검증이 남아 있었다.

투표 미리보기 검증 후 이전/중간 패키지와 이번 빌드 중복 **약 2.32GB**를 정리했다. 작업 폴더는 정리 직후 **약 3.29GB**다. 실행에는 약 922MB인 `testbuild`만 필요하며 나머지는 개발용 모델·NuGet 캐시·검증 자료다. 생성·번역 모델과 과거 채점 모델의 고정 출처·해시는 보존했다. 현재 앱 실행과 준비된 모델을 사용하는 C# 빌드·패키징에는 Python이 필요하지 않다.

Git에는 기획·개발 문서, 변환·추론·검증을 재현할 소스와 잠금 파일, 최종 보고서·모델 출처·라이선스를 보관한다. 실행 로그·프로파일·잠재값·실행 환경 및 용량 스냅샷은 로컬 산출물로 제외한다. 보고서의 로컬 산출물 링크는 이를 보관한 개발 PC에서만 열리며, 저장소 복제만으로 원본 실험 결과가 내려오지는 않는다.
